# 台湾腔（台湾国语）写法

台湾腔 = 台湾国语，是普通话的台湾变体，不是台语（闽南语）。写台湾角色台词时用这套：重点是台湾用词、句尾语气词、惯用语，腔调不卷舌、尾音上扬。

## 六、台湾腔怎么标进提示词

对白语言三要素里这样填：

- **语种**：国语（普通话）
- **腔调**：台湾腔 / 台湾国语腔
- **声音特征**：不卷舌、语气词多、尾音上扬带撒娇感

范例：

```text
对白 小美｜国语·台湾腔｜不卷舌、语气词多、尾音上扬
{厚，你真的很机车欸！}
```

## 七、台湾腔发音特点（写声音质感用）

- 平翘舌不分：zh/ch/sh 偏 z/c/s
- 几乎不用儿化音
- 句尾语气词多且拖音
- 尾音上扬，带撒娇 / 软糯感
- 个别字音不同："垃圾"读 lè sè，"包括"的"括"读 guā
