# 七段式结构与执行契约写法

从 4 个电影级范例提炼。骨架顺序固定，内容按题材替换。每段讲清"写什么"，经验直接写进正文。

## 【1.全局设定】第一句锁死质感

第一句就定"实拍还是动画"，后面所有写法都跟着它走。

电影级范例的开场：`真实电影摄影机实拍的画面，实体道具与实体烟火药，白天晴空高光比，镜头有脏污，持机被事件打偏。`

这一句的职责：立刻排除三维渲染 / 插画 / 卡通 / 游戏引擎质感。

接着写 3–5 样"实拍证据"，让画面可信：

1. **实体道具声明**：怪人是"穿硬质胶皮戏服的表演者扮演，甲壳是涂装过的发泡与树脂"；战机是"手工涂装的实体模型，漆面不均、边角磕碰露出浅灰底、板缝积灰"。给"这东西是真的"一个具体落点，而不是空喊"写实"。
2. **光影**：明确光源方向与硬软。`白天晴空高光比` / `侧逆硬光` / `单一日光硬光源自画左低位斜射`。
3. **镜头痕迹**：`镜头有脏污`、`持机被事件打偏`。这是"实拍"的物理证据，不是 bug。
4. **高速摄影规则**：区分主体与环境的物理时间。`尘与碎屑下落比重力慢半拍，主体动作仍为实时速度`。
5. **特效/物理总约束**：涉及火、烟、闪光、激光时，在这一段就定死行为边界。如 `全片没有爆炸`、`全片的颜色清单只有三种`。

实拍感不靠"胶片颗粒"这类空词，靠"具体某个东西是真的 + 具体某处有物理痕迹 + 具体某物慢半拍"。换题材时，把"胶皮戏服/涂装模型"换成该题材的实体载体：真道具、微缩模型、实体布景、真皮衣、真火焰。

## 【2.素材绑定】每张图只干一件事

用 `@图片N` 占位符绑定参考图，每张图明确两件事：**只定义什么**、**不得继承什么**。

- `@图片1 只定义男主的长相与衣着：凌乱黑发、耳钉、颈链、黑皮衣内黑衬衫。`
- `不得继承：白底、分格拼贴、图上标注、正面对称站姿。`
- 首帧锁定：`@图片5 就是本片首帧：第一帧与该图同构图同光，从这一帧直接动起来。`
- 音色绑定：`男主音色 @图片5`、`女指挥官音色 @图片7`。
- 动作参考与画面效果分离：`@图片6 只定义一个动作……它是动作参考不是画面效果，全片只用一次。`

要点：

- 一张图只干一件事（长相 / 形体配色 / 地理器物 / 动作 / 音色），不一张图扛全部。
- "不得继承"比"只定义"更重要——它挡掉参考图自带的脏信息（白底、排版、标注、游客、棚拍背景、俯视航拍）。
- 首帧图单独声明"同构图同光"，让片子从参考图原地启动。

## 【3.画面契约】主体怎么认、怎么保持连续

- **特征串**：一次性写全主体外观锚点。`黑色硬质甲壳、白色条纹与圆斑、巨大复眼、黑白环纹触角、两对带翅脉的透明翅、六肢利爪；体型只有成年人那么大。`
- **识别位**：多个同型主体时必须给出区分手段。`受创机灯线是琥珀黄，其余三架红`、`误中机垂尾外侧刷灰白色 02`。认人不靠脸，靠灯线颜色＋花名＋编号。
- **同框上限**：`画内战机不超过两架`、`同一帧只出现一次`。
- **材质/物理连续**：`触角、裂口毛边与松脱甲片不受主体动作起止约束，停住后仍各自延迟晃动`。这是"活物感"的关键——静止不等于僵硬，给每个主体留一点"收不住的惯性"。

特征串换成本题材的主体外观；识别位用于任何"多个同款"的场景（多架战机、多只怪物、多台机甲、多个克隆人）；"收不住的惯性"适用于任何有附属结构的主体（头发、衣摆、触角、天线、缆线、羽毛）。

## 【4.执行契约】导演怎么拍

这是提示词含金量最高的层。契约按需写，没有的机制不硬造。

### 速度契约

`全片 17 镜、16 切点；台词镜最长 2.8 秒，其余单镜最长 2.0 秒。` 给全片一个节奏底线，防止模型拖慢或乱切。

### 迟切规则（24 帧每秒）

重击 / 接触事件不立刻切走，按三段依次留满：

- **形变**：接触瞬间的形变（鞋底压平、白斑凹进）
- **失衡**：重心失控（上身扑出、身体倒飞）
- **代偿**：找回平衡（拧腰抢半步刹住、张开三肢抵住自旋）

`接触帧 X，切点 Y，晚约 N 帧；三段依次留满才切，接触时机位不换。`

### 机制锁

给特殊机制（咏春、火、瞬移、闪光）写死"只按这套来"的规则，防止模型自由发挥。

- 咏春机制锁：把专业术语翻译成可见动作——`连消带打：一只手黏住来招往斜里带的同一拍另一只手已打出去；拳从胸口正前方直着打出、直着收回`。
- 火是实体：把特效写成有质量、有延迟的实体——`火根与皮肤之间有一道深色湿边`、`拳面先到、火慢半帧才撞上`。

### 句法主动权

指定谁作主语，锁定画面焦点。`怪人一律作主语写主动句`，并给指定句：`怪人离地一掌平弹让过这一脚`。

### 对峙/轴线契约

多人关系锁定方位，全片不换边。`嘉豪在画左、怪人悬在画右低空，全片不换边；两者之间六格铺装花纹始终空着`。

### 摄影

- 机位档位循环，相邻两镜不得同档：`贴他、贴怪人、双人关系、贴地细节`。
- 统一质感：`手持肩扛、低机位为主、浅景深`。

### 音频

音效用 `<...>` 标注，对白用 `{...}` 标注，二者并列。音效只写画面里真实能听见的：`<皮鞋底碾过铺装砂粒的脆响>`。对白写法见 [02-dialogue-and-language.md](02-dialogue-and-language.md)。

## 【5.场景】

地点 + 光源 + 空场状态 + 地理锚点，三四句说清。

`白天的滨海游乐园中心广场，侧逆硬光。园区已疏散：设施全部停机、灯全灭，摩天轮定死在原位。`

## 【6.分段计划】段是叙事单位不是镜头单位

- 第一句声明：`段是叙事单位不是镜头单位，段内多切。`
- 每段一行头：`段一 入场 0.0–3.5，段内 3 镜`。
- 段内写动作因果链（谁→做什么→后果→镜头），不是分镜流水账。
- `末：`收尾，独占该段最后一镜，给下一段一个可承接的终态。

## 【7.负向约束】只拦最可能翻车的

编号列"不要……"，最多 5 条。高频复用项：

1. 不要卡通渲染、游戏引擎质感或塑料玩具感
2. 不要线稿、白底、涂色书画风或无光影的平涂
3. 不要叠加字幕条、标题卡与水印
4. 不要人手指节融合、不要同一只手改变手指数量
5. 不要 bgm、不要字幕

负向约束只写"这个题材最可能翻车"的项：打斗写"手指融合"，空战写"不要航展式侧掠展示"，恐怖写"不要定格亮相"。别把通用项堆成 20 条。
