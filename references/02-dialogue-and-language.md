# 对白与语言写法

对白是提示词里最容易写糊的部分。这套写法从 4 个范例提炼，核心是把"谁说、说什么、用什么语言、什么语气、什么时候说、口型对不对"一次讲清。

## 位置与格式

对白写在【4.执行契约】的音频区，与音效并列，不单独成段。

```text
对白 角色名｜语言＋方言＋腔调｜声音质感/声道（可选：生僻字读音）
{台词原文}｜落点 起–止｜口型/表情/与画面事件同帧的绑定描述
```

多句台词依次列在同一角色名下；多角色用 `对白一/对白二` 或 `对白 角色名` 区分。

## 语言规定三要素（缺一不可）

1. **语种**：粤语 / 普通话 / 英语 / 其他方言
2. **方言/白话层级**：广府白话 / 港穗腔 / 东北话 / 川渝话……
3. **腔调**：痞腔 / 干净利落都市腔 / 咬着牙的狠 / 懒洋洋拖着笑 / 冷静命令式

范例：

- `粤语广府白话，痞腔`
- `粤语广府白话，干净利落都市腔`
- `粤语广府白话，港穗都市腔`

三要素任意组合：语种＋方言定"听感"，腔调定"态度"。同一句普通话，腔调换成"怯腔"和"狠腔"是两个人；换成"哽咽"和"笑骂"又完全不同。

台湾腔（台湾国语）的用词、语气词与叫法见 [04-taiwanese-accent.md](04-taiwanese-accent.md)。

## 声音质感与声道

决定声音"从哪来、经过什么介质"。范例：

- `白天外景原声`——室外直接收音
- `座舱人声与无线电混叠，有喘息风噪，音量为吼`——特定场景的收音质感
- `窄带压缩的纯无线电人声`——经过设备传输
- `舱内原声`——室内直接开口

声道要和场景物理一致：车内对讲、电话、对讲机、广播、扩音器都要写清介质，否则模型会给你"棚里干净的播音腔"。

## 台词与叙述的分界

- 台词用 `{...}` 包裹，绝不和叙述混写。
- 语气标注落在具体字词上，用「」引用，而不是整句笼统写"凶狠地说"：
  - `「屎忽」两字忽然咬重，尾音「㗎」拖长上挑`
  - `「夜粥」咬重放慢`
  - `「死人頭」三字逐字咬重`

## 生僻字/多音字给读音

粤语多音字、生僻字直接给注音，防止模型读错：

`读音：吓 haa5、喎 wo5、印 jan3、起 hei2`

凡是模型可能读错的字（多音字、方言字、生僻字、外来语、数字代号），一律跟注音。粤语发音与地道俚语查询见 [03-cantonese-phrases.md](03-cantonese-phrases.md)。

## 落点：什么时候才标时间

落点不是每句必标。只在以下三种情况标：

1. **口型可见**：`口型可见的单一镜头内说完`——这句必须有清晰口型
2. **与画面事件同帧**：`末字与下属拇指落到键帽上同帧`、`与他拳一张、火自指缝炸开同帧`
3. **跨镜作画外音**：`尾音「喎」自 4.2 拖长上挑，压在 4.2–5.0 的怪人镜上作画外音`

普通对白一句话带过，不需要精确到 0.01 秒。

## 语气与节奏

情绪写成"怎么形成"而不是贴标签：

- `懒洋洋的痞腔，前七字拖着笑、近乎赞叹`——先赞后咬
- `两个字咬满压着劲`——短促有力
- `呼号与人名之间断半拍`——节奏断点
- `音量收着`——收着说比吼更有戏

## 多角色与共享底噪

- 两个以上角色时，每个角色单独一块"对白 角色名｜语言｜声道"。
- 共享同一环境声时最后补一句：`两句共用同一层无线电底噪`。
